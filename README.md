# ZIP to Static Site

Quero que você transforme integralmente o conteúdo do arquivo ZIP enviado em um site estático, pronto para ser armazenado em um repositório novo do GitHub.

REGRAS OBRIGATÓRIAS:

1. Preserve absolutamente todos os arquivos, códigos, componentes, funcionalidades, estilos, animações, imagens, fontes, ícones e estruturas originais do ZIP.
2. NÃO modifique, reescreva, reorganize, remova, substitua ou simplifique absolutamente nada do projeto original.
3. NÃO faça melhorias, atualizações, refatorações ou alterações visuais.
4. Mantenha a interface, o comportamento e a identidade visual exatamente como estão no projeto original.
5. Transforme o projeto em um site estático, utilizando somente os recursos necessários para executá-lo diretamente pelo navegador.
6. O site deve funcionar 100% OFFLINE, sem depender de internet, servidores externos, APIs, CDNs ou serviços de terceiros.
7. Todos os recursos necessários devem estar incluídos localmente no próprio projeto.
8. Elimine qualquer dependência de conexão externa durante a execução do site, sem remover funcionalidades originais.
9. Garanta compatibilidade com hospedagem pelo GitHub Pages.
10. Não adicione rastreadores, telemetria, analytics ou processos desnecessários.

SOBRE O GITHUB:

Prepare a estrutura final para que eu possa criar um repositório novo e enviar todos os arquivos diretamente para ele.

O resultado deve permitir abrir o site pelo GitHub Pages, mantendo todas as funcionalidades originais.

ATENÇÃO:

Não quero uma reconstrução do projeto, uma nova versão ou uma edição do aplicativo.

Quero exatamente o mesmo projeto que está dentro do ZIP, apenas convertido e preparado para funcionar como um site estático, preservando sua identidade e seu funcionamento.

Antes de finalizar, verifique se todos os arquivos necessários estão presentes, se os caminhos dos recursos estão corretos e se o funcionamento offline foi preservado.

Prioridade absoluta: FIDELIDADE AO ZIP ORIGINAL. NÃO MEXA EM NADA ALÉM DO ESTRITAMENTE NECESSÁRIO PARA A CONVERSÃO.
